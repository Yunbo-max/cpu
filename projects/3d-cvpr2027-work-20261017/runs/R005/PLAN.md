# R005: Can observable accelerometer-window quality predict gravity error?

Development diagnostic on the same exposed official TUM fr2/xyz sequence; no pose-effectiveness or novelty claim. Reuse R003's first-30-second fitted sensor-to-camera rotation and world specific-force direction without refitting. Recreate its predetermined 10-Hz timestamp grid, GT <=12 ms and at least five accelerometer samples in a ±20-ms window. Evaluate only timestamps 30–122 s after the first RGB frame. Ground-truth orientation is used only to score the angular error between the predicted static-gravity direction and observed window mean.

Predictors computed without query GT: (1) absolute deviation of mean acceleration norm from the median first-30-second norm; (2) within-window 95th-percentile direction dispersion; (3) standard deviation of sample norms. Score Spearman rank correlation with angular error, error medians in the highest versus lowest predictor quartiles, and AUROC for angular error >1.5° and >2.0°. If a class is absent, report undefined rather than a fabricated number. Use ten-second time-block bootstrap (seed 5005, 1000 draws) for Spearman 95% percentile intervals, recording effective block count. This addresses the simplest necessary assumption for a confidence-aware prior; any weak or inconsistent relationship narrows or kills this route.

Resources: one process, `OPENBLAS_NUM_THREADS=OMP_NUM_THREADS=MKL_NUM_THREADS=1`, 4,000,000,000-byte address-space limit, finite 120-second wall timeout. Record input hashes and CPU/wall/RSS. The data and sequence have already been exposed, so this cannot be held-out paper confirmation.
