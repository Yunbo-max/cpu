# PA-BPE Simple：第二次后台研究窗口报告

时间：2026-10-11（UTC）。项目 `pa-bpe-simple-20261011`；active idea `pa-bpe-domain-robustness` revision 1；Research Autopilot Simple `0.3.0-simple.9`。本窗口使用一个科学进程、一个线程，无 GPU、付费 API 或外部写入。

## 本轮结论

此前用 Hugging Face OPUS Books 连续行偏移构造的 dev/confirm 不能证明作品独立。独立审查和原生 XCES 文档身份共同表明，旧切片很可能都来自已暴露的 Alain-Fournier《Le grand Meaulnes》；旧分数仍是行级描述，但不再作为跨书确认。

原生 OPUS Books v1 已恢复并核验：EN-FR、EN-ES、ES-FR XCES 分别有 26、18、12 个文档组，三语交集为 12 部作品。三个原始 XML ZIP 的中央目录均可按字节范围读取，12 部作品在三种语言中全部存在。为验证管道，只选择压缩体积最小的两部完整作品：Alice 作为开发烟测（682 条三语一对一行），Poe《厄舍府的倒塌》作为确认烟测（264 条）。二者的原生 XML、句子 ID、成员名和 SHA256 均已冻结；这是资源受限管道验证，不是多书确认实验。

对现有九个英法 tokenizer 的作品级评分得到混合结果：

| 方法 | Alice Gini | Alice 总语言均值 | Poe Gini | Poe 最差语言成本 | Poe 总语言均值 |
|---|---:|---:|---:|---:|---:|
| Classical BPE | 0.002063 | 66.801 | 0.007505 | 61.477 | 121.136 |
| pooled PA-BPE | 0.022992 | 68.302 | 0.011708 | 62.826 | 122.777 |
| robust-domain | 0.013865 | 67.891 | 0.003492 | 61.708 | 122.561 |

robust-domain 在 Alice 上明显不如 Classical，但在独立 Poe 作品上 Gini 更低；同时 Poe 的最差语言成本高约 0.38%，总成本高约 1.18%。因此 robust-domain 在 Poe 上改善均衡度但没有 Pareto 支配，且“一定发生跨域公平收益丢失”的预测没有被支持。只有一个开发作品和一个确认作品，不能推断总体跨书稳定性；必须扩展为多作品宏平均。

机制回看显示 robust-domain 的 1000 次合并中有 220/999 个可比较步骤对当前被选中的最差开发切片没有正 token 收益，高于 pooled 的 154/999 和 base 的 174/999；其选择器切换 214 次，且 818/1000 次选择 TICO 域。这提示“只允许对所选最差切片有正开发收益的候选合并”值得作为后续候选，但在多作品基线确认前不实现或调参。

## 数据与访问状态

- FineWeb2 直接 Dataset Viewer 的西语请求返回 HTTP 500；猜测的 `refs/convert/parquet` 路径返回 404，均已停止重复请求。
- 仓库元数据给出的正确文件是 `data/spa_Latn/test/000_00000.parquet` 和 `data/spa_Latn/train/000_00000.parquet`。对 `main` 的 4 KiB 范围请求均成功并读到 Parquet `PAR1`：测试分片 59,698,497 bytes，首训练分片 4,846,280,144 bytes。后者不适合本阶段整片下载，下一轮应使用可审计的范围/行组读取或改用更小且许可清楚的训练源。
- OPUS Books 原始归档总压缩大小：英语 72,871,773 bytes，法语 33,835,983 bytes，西语 22,269,907 bytes。选择性范围提取避免了下载全部 129 MB。

## 失败、修复和资源

本窗口 runner 共使用 10 次 attempt，科学命令累计 wall 352.624 秒，峰值 RSS 最大约 32.6 MiB；父阶段累计 402.028/3600 秒，剩余 3197.972 秒。无活动科学进程、未知 reservation、OOM 或 timeout。

保留的失败包括：一次非法 task phase 配置（未启动任务）；一次重复 supervisor 启动被唯一锁正确拒绝（未启动任务）；两个 ZIP 成员匹配诊断错误地假定目录/扩展名并产出全 null，后以完整成员名清单修复；首次作品级评测因 CSV 把句首双引号当引用符而退出 1，wall 0.143 秒，后用 `QUOTE_NONE` 和严格六列检查修复。所有失败输出和回执均保留，未计为科学结果。
