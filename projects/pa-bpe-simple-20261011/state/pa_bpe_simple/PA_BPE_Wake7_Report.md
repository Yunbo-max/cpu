# PA-BPE Wake 7：GlobalVoices 三语确认源结构门禁

本轮只推进来源、许可证据和内容对齐身份，不读取语料正文，不运行或选择分词器，也不计算公平结果。宿主共享内存余量仅约 1.24 GB，因此没有启动训练。

独立来源审查把 OPUS GlobalVoices `v2018q4` 判为条件性 GO：Global Voices 原文有 CC BY 3.0 归属政策，三份 XCES 对齐保留文档引用和句 ID；IWSLT/TED 因当前条款及缺少同套英法西数据判为 NO-GO，MDN 因缺固定句级三语身份暂 HOLD。该审查是来源证据，不是法律意见。

先对官方 ILSP Parallel Global Voices 2015–2016 的 `docpairs.txt.zip` 做独立结构诊断。下载对象 3,096,610 字节，SHA-256 `d270acc7c000a30a79138d1f6259150641b444229ff10167efc36b2cbedeedfd`，ZIP CRC 正常，302,617 条记录与官方统计一致。英法、英西、西法分别有 14,930、29,645、11,366 个文档对；11,004 个英文文档具有三边闭合的英法西文档三角。句段三语身份未核实，因此 PGV 仅文档级 qualified。

随后下载并固定 OPUS GlobalVoices `v2018q4` 三份 XCES：en-fr SHA-256 `2eda1355...`, en-es `a7e928c2...`, es-fr `beabbf7e...`。它们分别包含 16,305/379,691、32,844/752,052、13,255/359,107 个 linkGrp/link，全部具有 `fromDoc`、`toDoc` 和 `xtargets`。在结果出现前冻结：每个英文文档只取字典序第一组三边闭合文档三角，按文档三元组 SHA-256 排序检查前 512 个；把 XCES 多对多链接构成图，仅保留同时含三语言且包含三种语对边的闭合连通分量，再按单位 ID 哈希冻结前 512 个。

结构结果：全量有 12,374 个一英一组三边闭合文档三角；冻结的 512 文档范围内保留 en-fr 12,747、en-es 12,729、es-fr 13,139 条非空链接，得到 11,919 个闭合三语全边单位，重复单位 ID 为 0；另拒绝缺语对边分量 144、缺语言分量 1,098。512 个单位身份已冻结。它只证明确认集结构可构造，不证明翻译质量、数据独立、许可覆盖到每条异常内容，亦不证明任何 tokenizer 公平。

四个串行科学 attempt 全部 exit0；runner 计费 wall 42.196157121 秒、reservation 0、最高 RSS 86,224,896 bytes。项目累计计费 wall 822.478601943 秒，不清零且无项目累计上限。两个提交级错误（未知 phase、越界证据路径）均在启动前被拒绝，未占 attempt，已保留并修复。空闲 supervisor 在全部任务终态后受控退出，无未知作业。

下一步仍属于同一 active idea：在打开 raw 文本前核查署名字段、许可例外和训练/开发来源清单泄漏；另行恢复来源完整的西语训练；随后前瞻冻结 tokenizer 候选、词表、预分词、逐行 Gini、最差语言及总 token 成本约束和确认分析。GlobalVoices 确认结果只能在这些门禁后打开。
