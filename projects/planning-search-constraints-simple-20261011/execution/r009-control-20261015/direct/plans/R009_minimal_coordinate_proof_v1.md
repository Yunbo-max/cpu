# Hierarchy-preserving minimal-coordinate simple control

Prospective public derivation, same research idea; ordinary implementation control, not a novel algorithm.

Let a state S be Cartesian domains S_v and a separate spurious flag e(S). For immutable converted operator o, define a_v(S,o)=[S_v intersects P_ov], r_v(S,o,T)=[effect_ov in T_v] for a fixed effect, otherwise [S_v intersects P_ov intersects T_v]. Native A=(not e(S)) AND conjunction_v a_v; R=(not e(T)) AND conjunction_v r_v. All intersections and flags use exact native integer/bitset semantics. No floating approximation.

For committed split p to children c1,c2, define U={v:S_pv differs from S_c1v OR differs from S_c2v}. Child domains shrink, operators are fixed, all other states unchanged. Outside U, each relevant source/target domain equals the old parent's coordinate. Each coordinate factor for an inherited true relation therefore remains true. Hence checking all v is equivalent to checking v in U, provided global spurious guards stay unchanged and the old relation is valid.

Incoming u->p: old applicability of u remains true; only target coordinates can change, so R(u,o,ci) requires U only. Outgoing p->w: both A(ci,o) and R(ci,o,w) require U only. Parent loop p->p: all four pairs(ci,cj) may change both endpoints, but outside U both still equal p; check A(ci,o), R(ci,o,cj) on U and preserve committed self-loop inclusion/multiplicity. An empty U gives an empty conjunction, not zero cost of the global flag checks. Reachability depends on target; no cross-target/split cache is introduced. Restrict first experiment to policy NONE and committed, not simulated refinement.

Source invariant is as consequential as algebra. Original Abstraction::refine also mutates refinement hierarchy in the same loop guarded by splitvar. To avoid changing that behavior, the proposed overlay retains that original guard and all hierarchy calls verbatim, removes only original modified_vars.push_back, and adds a separate per-analysed_var domain equality check that appends precisely U in increasing order. The old hierarchy loop may retain redundant comparisons: this control tests predicate-coordinate work without changing hierarchy semantics, not the fastest imaginable implementation. Non-disambiguated branch remains original {splitvar}; native qualification must show this also equals U on actual data. All goal/spurious/rewire order code stays unchanged.
