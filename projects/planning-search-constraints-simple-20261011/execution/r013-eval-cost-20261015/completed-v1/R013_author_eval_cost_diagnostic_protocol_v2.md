## Question and decision

CPU cost. Fresh timer.cc source inspection corrects prior R012 field/prose labels:
on Linux these author Timer values are PROCESS_CPUTIME_ID CPU, not wall. Preserve

measurements are unchanged. In particular improve_heuristic_timer encloses ordinary evaluation as

## Intervention and scope

Create one isolated replacement of the author's online-heuristic .cc TU. No old
source/header/.o/binary edits, no header/layout changes, no solver RNG changes.
Freshhash the author source manifest, GNU flags, all reused original objects and
the repaired HM object. Replace exactly that TU in the retained link argv.

At each compute_heuristic entry, increment a separate uint64 diagnostic index.
A fixed splitmix64 mapping selects low10bits==0 (~1/1024); this is deterministic,
not a random sample or an unbiased estimator. Clock only selected queries at
entry/after convert+dead-end check/after abstract-state IDs/after compute_max_h/
exit, using CLOCK_THREAD_CPUTIME_ID. Early-return strata and sample counts remain
explicit. Four disjoint durations sum exactly to each sampled query duration,
including clock/read/observer overhead. No subtraction pretending intrinsic cost.
Ordinary and online-event-containing sampled queries are reported separately.

Independently time EVERY online creation block from entry before order computation
through remaining costs/SCP computation/conditional storage/new_h update. Its
CPU sum is a complete instrumented interval census, not a sample; it overlaps
the tail of any sampled query containing it, so NEVER add both to one total.
All query/early-return/online-event counts are retained. No per-predicate allocation
of aggregate CPU differences, no internal wall-minus-CPU wait claim.

Native complete wait4 user+systemCPU/wall/RSS remain separately measured, including
exec/init/construction/search/exit, excluding parent preflight/hash/VAL. This is
an instrumented diagnostic binary: do not compare its time to R012 as speedup or
call sample extrapolation an original-author exact cost decomposition. Report raw
sample_ns/sample_count and explicit conditional descriptive projections only.
Sampling alias/representativeness remains uncertain; online events are fully timed
to avoid interval10000/sampling1024 aliasing. No confidence interval or sample-unit
independence claim. One exposed p06 condition, not broad public coverage.
