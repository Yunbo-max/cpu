## S12 · AI4Science inverse-design confidence under simulator shift
Closest primary **accepted ICML 2026**: de Campos, Krebs, Gottschalk, *Generative Inverse Design with Abstention via Diagonal Flow Matching*, https://proceedings.mlr.press/v306/de-campos26a.html . Pin original MIT code migueldecampos/diagcfm@d1afc35f325ecc22e0401b931b72b442b50370f2, diagcfm_core.py Git blob 84054d130ffebe1386610e05e53d0915aa0e8bf3. Actual functions: state t0=[z,y], t1=[x,0]; predict_labels integrates from [x,0] backward; zero_deviation squared tail; self_consistency resets tail to 0 and reconstructs label. Model's z is Uniform(0,1).
An **invertible affine time-one ODE** Φ(z,y)=(epsilon*z+y+b, -epsilon*z), epsilon>0, has det Jacobian=epsilon>0 and a REAL 3x3 homogeneous matrix logarithm. For target y, generated design x=y+b+epsilon*z; two internal uncertainty scores are BOTH epsilon²z². In a source-compatible training simulator f_train(x)=x-b the true train-physics error is epsilon²z²; in a shifted deployment simulator f_deploy(x)=x the true error is (b+epsilon*z)². At b=.8, epsilon=.01 and N=2000 independent seeded synthetic (y,z) pairs, both intrinsic scores average 0.00003432763 yet deployment physical error average 0.64816443 (ratio 18881.7x). Taking epsilon->0 makes internal scores ->0 while deployment error ->b². This proves that intrinsic cycle and zero scores **cannot certify unknown true-physics shift** without external simulator data. It does **NOT** prove trained Diag-CFM fails: its paper tests roundtrip ground truth (exact DTLZ/physical proxy), a shifted simulator is beyond the stated data source, and the affine ODE was not learned by its optimiser. Flow/diffeomorphism manifold dimension limitations and surrogate-bias checks are classical prior. See evidence/R024_S12_deep.md and receipt.
