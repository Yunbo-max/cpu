## Exact synthetic counterexample
For m independent bits x_i in {0,1}, construct m internally vertex-disjoint monitored s-t paths, each bottleneck edge e_i of capacity 1+x_i, plus one disjoint compensating path of capacity 1+m-sum_i x_i. All return edges have capacity >=m+2.
The static max flow is F(G_x)=2m+1 for ALL 2^m graphs; the vertex and edge support is identical. After deletion of monitored edge e_i, F(G_x-e_i)=2m-x_i.
Thus all m fault-response values recover all m bits. Any finite B-bit sketch with worst-case absolute query error <1/2 and correct original-edge identity handling must use B>=m bits. For iid fair X and uniformly sampled fault index, expected bit-decision error D requires B>=m[1-h_2(D)] by the classical binary entropy / information bound. These are elementary indexing/rate-distortion consequences, NOT a new lower-bound result. They do not imply HyDRO+ actually fails: no condensed model was trained or tested.

NetworkX 3.6.1 CPU verification enumerated m=8, 256 exact graphs and 2,048 single-edge deletion max flows. Each static max flow was 17 and all 256 fault-response vectors were distinct; process CPU 0.30155968 seconds on the bounded local witness.
A second k=3 construction with a common unit bottleneck and k vs k+1 parallel backup branches yields identical responses to ALL monitored failure sets of size 0,1,2, but gives different flow outcomes 0 vs 1 when all 3 monitored branches fail. A second- or first-order failure summary therefore does not identify third-order synergistic exposure.
