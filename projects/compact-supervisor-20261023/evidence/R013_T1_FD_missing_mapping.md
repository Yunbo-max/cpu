Construct D0: (a,0),(a,0),(b,1),(b,1) and D1: (a,1),(a,1),(b,0),(b,0). Provide EXACT same candidate relation graph {nodes: [region,code], edges: [{source:region,target:code,type:hierarchical,rule:''}]}. Both datasets satisfy the FD region->code perfectly, with zero conditional entropy H(code|region)=0. Yet the optional CRKG compressed CSV of region values is identical, its validation confidence 1.0 and its saved graph/reconstruction descriptor identical. Distinct original tables map to the SAME encoding. Without previously saved mapping side information the encoding is not injective: no decoder can recover both.

Stronger combinatorial bound: K distinct source keys independently assigned among q target labels yield q^K possible valid deterministic functions, all identical under this fixed compressed-output format when only the source keys and relation descriptor are retained. Exact reconstruction of arbitrary mappings requires at least log2(q^K)=K log2(q) extra bits, assuming no external side information and uniform prior; this can be realized as a lookup dictionary or other equivalent representation. With two equiprobable swapped maps above, the best row-level deterministic decoder reaches 50% correct on average over the two source tables.

Executed in-chat cheap Python mirror of the source's relevant validation and serialization code, but DID NOT import original TabKG modules, call the LLM, train a diffusion model, or run the full generated data/decompressor. Separate exhaustive K=5,q=2,3 rows per source category: 32 valid functions, one common compressed-data/descriptor output, missing-information bound 5 bits. Source-exact scoring was reused, but implementation-level guarantee must be scoped to *two saved CRKG artifacts for a fixed candidate graph*; if another production component saves a mapping in a different place or keeps a complete original raw table, this strong impossibility claim no longer applies to that full system.

Closest existing work: 'Compressing table data with column dependency', Theoretical Computer Science 2007, https://doi.org/10.1016/j.tcs.2007.07.016, explicitly exploits stored column dependencies for compression. This elementary decoder-metadata requirement is NOT a new theory paper or accepted algorithm. Independently prior PR 2025 FD/LD and UAI 2025 approximate FD also weaken broad novelty claims.
