# R012 · G1: outage snapshot counts can invert the query-distribution optimum

Project parent Git SHA 978caea1dc52dbe9cdcbb50baaf149a607e4bcfe. Scientific node G1, independent from T1.

**Real data discovery (NOT YET DOWNLOADED):** The NYISO primary P-54B archive publishes real-time *actual* transmission line outage CSV plus archived ZIP listings at https://mis.nyiso.com/public/P-54Blist.htm . Carrington, Dobson & Wang (2021 IEEE NAPS, DOI 10.1109/NAPS52732.2021.9654559) describe repeated approximately 5-minute status snapshots, with PTID and outage start time. Secondary schema catalogue: https://askthegrid.com/catalog/nyiso_rt_line_outages (event_time, ptid, outage_time, ingested_at). Counting every row as an independent *failure event* is unjustified: long-lasting outage episodes appear in more snapshots. Primary index was found, but no raw P-54B CSV was retrieved or decoded in this round.

**Mathematical observation model:** Under stationarity, incidence rate lambda_e and event duration D_e, periodic sampling interval Delta, normalized *event* query probability is proportional to lambda_e, while a snapshot/occupancy query probability is proportional to lambda_e E[D_e]. Which is right depends on the target question. Both can be legitimate; snapshot count is biased ONLY when estimating new incident arrival frequencies from an occupancy feed.

**Executed synthetic counterexample:** A has 1 event lasting 1440 minutes and B 100 events lasting 5 minutes; at 5-minute sampling (ideal aligned nonoverlapping event setup), A contributes 288 snapshots, B 100. With two independent fair response bits and one bit storing one coordinate, snapshot-optimal cache=A and incident-optimal cache=B. Event-weighted Hamming losses are respectively 50/101 and 1/202, 100x apart. The example is purely synthetic, illustrating classical length-biased sampling. See evidence/R012_G1_duration_toy.json and R012_G1_duration_probe.py. In-chat Python CPU was 0.001209733s; script is an equivalent independent reproducer, not the executed byte-identical file.
