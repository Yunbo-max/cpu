D2. Exact 2-action falsifier. W={e1,e2}, c0=(0,.2), U={c0+d:||d||2≤1}, sigma=(1,1), κ=1. The optimal observed decision w_i=e1. The pinned static label generator gives `c_worst=c0 + e1 = (1,.2)` (source worst observed action cost). Suppose predictor outputs w_pred=e2; the static scenario loss R(e2,c_worst)=0 because e2 is optimal at cost (1,.2). But ACTUAL worst-case regret over U equals sup_{||d||≤1}max(0,(c0_2+d2)-(c0_1+d1)) = .2 + sqrt(2) = 1.61421356237, attained at d=(-1,+1)/sqrt2. For w_pred=e1, source regret=.8 whereas genuine worst-case = sqrt2-.2=1.21421356. Hence frozen labels cannot exactly represent current-prediction worst-case regret in general; does NOT prove their SPOPlus objective never improves empirical robustness.

D3. Rival explanations and simple repair. Static adversarial dataset is a legitimate computationally cheaper surrogate; authors might intentionally precompute labels rather than solve nested minimax every gradient step. It can still improve validation regret under shift. A direct conditional adversarial oracle should maximize R(w_pred,c) for each predicted decision (or compute a conservative upper bound), at extra Gurobi/time cost. It is NOT necessarily differentiable and may have adverse bias/variance. Other simple repair: compare fixed versus alternating adversarial updates, radius-shrinking and no-risk baseline under matched oracle calls. If original full pipeline already solves prediction-dependent robust regret elsewhere, narrow claim further.
