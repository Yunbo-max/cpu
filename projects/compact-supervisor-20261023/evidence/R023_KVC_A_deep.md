D1 (operator and information): In one-head standard softmax attention, query q sees cached token keys k_i and values v_i, has full-cache output y=sum_i a_i v_i, a_i=softmax(q.k_i). The eviction policy observes an attention sample, logits, values and full output; an OBCache scorer assigns one scalar per token before top-k retention. Future queries/LLM outputs are NOT observed by the diagnostic. Budget precisely one retained token, zero protected slots, one query, one value dimension. This corresponds only to source-supported obcache-k/obcache-v/obcache-vk scoring, not the deployed default observed-window setup.

D2 (exact consequence): choose n >=2 useful tokens v=1 and one anchor v=0; give all n+1 tokens logit=1 and a=1/(n+1). Then y=n/(n+1). From official obcache-k compute_k_score, s_i=(a_i*logit_i)^2*(v_i-y)^2. Therefore s_anchor=n^2/(n+1)^4; s_useful=1/(n+1)^4. Ranking descending s and retaining one token keeps the anchor. Under attention re-normalization to that sole retained token, output y_anchor=0, squared discrepancy L_anchor=n^2/(n+1)^2. Keeping any useful token outputs y_useful=1, L_useful=1/(n+1)^2, so top-k selector has a global squared-loss approximation ratio n^2. The EXACT single-token-deletion error also ranks anchor n^2 above any useful token: deleting anchor changes y by 1/(n+1), deleting a useful token changes y by 1/[n(n+1)]. Single-item influence DOES NOT imply set-function cardinality-budget utility. This is a constructed theorem for this score and setup, not a new universal attention impossibility.

D3 (falsification and simple repair): The SAME pinned source implements obcache-v score a_i^2 ||v_i||^2 and obcache-vk including value/key cross term. Both choose a useful token and obtain optimal budget-1 squared error in this witness. Iterative scoring, preserving representatives, group-aware reconstruction are other simple repairs. Thus broad method failure is FALSIFIED and paper novelty heavily limited. Protection windows, other queries, GQA, adaptive budgets, value projections and downstream logits could change effects.
