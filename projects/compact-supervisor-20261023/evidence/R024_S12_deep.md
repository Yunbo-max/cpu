# S12 (R024) — Invertible zero-anchored inverse-design ODE cannot certify physical truth under simulator shift

Status: deep_mathematical_record, NOT native-validated and NOT an accepted new idea. Research parent 9ae425bcd3cbb32d998080bbb086584b98791f95. Separate peer ROOT screening from S13.

D1. Exact operator and information. Diag-CFM original ICML2026, https://proceedings.mlr.press/v306/de-campos26a.html, public code migueldecampos/diagcfm@d1afc35f325ecc22e0401b931b72b442b50370f2; diagcfm_core.py blob 84054d130ffebe1386610e05e53d0915aa0e8bf3 defines source [z,y] with z~Uniform[0,1]^P, target [x,0_L]; continuous ODE transport, Euler solver, Zero-Deviation = ||tail_out||²; Self-Consistency = average ||fhat(x_gen)-y*||² where `fhat` is SAME learned flow run backward after replacing tail by exact zeros. At decision time ONLY learned flow, requested y and latent z are available, NOT deployment's ground-truth physics. Physically evaluated error E||F_deploy(x_gen)-y||² is separate and in paper is computed using simulator or proxy.

D2. Exact affine ODE construction for P=L=1. Fix epsilon>0, scalar shift b>0 and matrix A_eps=[[epsilon,1],[-epsilon,0]], c=(b,0). Φ(z,y)=A_eps(z,y)+c = (epsilon*z + y + b, -epsilon*z). det(A_eps)=epsilon>0, so it is invertible and orientation preserving. The 3x3 homogeneous map H=[[A,c],[0,1]] has a real matrix logarithm for tested positive epsilon (complex conjugate eigenvalues off negative real axis). This yields a time-1 smooth affine ODE, not an arbitrary noninvertible map. Forward generation returns x_gen=y+b+eps*z, tail=-eps*z. Zero-Deviation u0=eps² z². Analysis of [x_gen,0] using Φ^{-1} sets zhat=0, reconstructs yhat=x_gen-b=y+eps*z; so Self-Consistency usc=eps² z². Training-simulator f_train(x)=x-b fits inverse up to eps*z; deployment simulator f_deploy(x)=x gives actual squared physics target error (b+eps*z)². For z~Uniform[0,1], E[u0]=E[usc]=eps²/3 and E[real error]=b²+b*eps+eps²/3. As eps->0, intrinsic scores vanish and true error approaches b²>0. Exact identity with all scopes, not a training-procedure claim.

A second structural fact: a finite-time diffeomorphism of R^{P+L} maps an open full-dimensional source support to an open set, which cannot lie EXACTLY in the lower-dimensional zero-tail manifold {tail=0}. Thus its tail must be approximate for nondegenerate (z,y) input. Making epsilon small increases the inverse condition number ~=1/epsilon (verified CPU 100x at eps=.01); near-zero tail is coupled with conditioning, but this is already known normalizing-flow manifold mismatch.

D3. Falsifier / alternative explanation / simple repair. The shift b is a data-generating/dynamics shift invisible to learned-only UQ; models evaluated against independent true simulator or held-out shifted deployment cases can detect it. Indeed Diag-CFM authors measure ground-truth round-trip MSE and their experimental results may be solid. If physical simulator is unchanged and its supervised training learns exact inverse, this engineered shift counterexample is irrelevant to real performance. A simple independent physics residual, or calibrated model ensemble/abstention using some real labels, repairs the *information* gap in principle (costly); no new algorithm proven. Any claim 'both internal scores always fail' is FALSE.
