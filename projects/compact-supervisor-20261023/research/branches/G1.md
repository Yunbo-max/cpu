# G1: fault query workload entropy
Mechanism: information per observed indexed fault query.
The 256-graph 8-bit family has 256 different full fault-response
vectors. If only the first two original edges can be queried, all
256 graphs reduce to four distinct query-response vectors, hence
two bits suffice for exact zero-error answers on that restricted
workload. This classical indexing fact is not a new theorem.
