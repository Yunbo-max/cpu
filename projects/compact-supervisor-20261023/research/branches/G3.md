# G3: original edge identity versus quotient invariance
Mechanism: missing query identity interface rather than bits or
failure interaction order. Two directed weighted graphs with s->p
and s->q branches of capacities 1 and 2 are isomorphic if p and q
are unlabeled. Both intact max flows equal three. The named
original-edge query delete(s,p) yields flow two in one graph and one
in the other. A permutation-invariant graph summary WITH NO original
edge identity map cannot answer both named queries. Supplying
edge IDs or a correspondence map resolves the ambiguity; this is
a conditional interface obstruction, NOT a universal GNN failure.
Next: check supported edge-ID mappings and identity-aware
graph summarization baselines at matching total bits.
Falsifier: named original-edge queries are absent or an existing
identity-aware reduction matches the whole storage and query budget.
