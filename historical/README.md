# Historical CPU research

94 original historical BoostFW, Consistent LRA B01–B15, and CPU feasibility files
retrieved from their persistent Library identities. Paused projects remain
paused. These files contain research artifacts, not chat conversation history.

`MANIFEST.json` preserves names, source versions, byte counts and SHA256.
`objects/<sha256>/index.json` lists ordered byte-exact 8 MiB parts. Concatenate
them in manifest order and verify the original SHA256 to reconstruct a file.
Identical contents are stored once even when several original filenames exist.

No deletion is authorized by manifest existence alone: the corresponding GitHub
commit must be published and independently verified first. Existing Library
files remain a fallback and are not deleted by this migration.

`IMPORT_SOURCES.json` and `EXTRA_SOURCES.json` retain the exact source identities.
The extra dated inventory closes gaps for standalone B04–B15 reports and the
early CPU reproduction package. Original sizes total 1,162,282,162 bytes;
84 distinct contents are stored. Unrelated personal documents and manuscripts
are outside this CPU experiment migration.
